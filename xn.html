Istruzioni dettagliate per ottenere le credenziali

🔵 Per Outlook (Microsoft Graph):

  1. Vai su Azure Portal → Azure Active Directory
  2. Clicca su Registrazioni app → Nuova registrazione
  3. Nome: Agenda Unita (o quello che preferisci)
  4. Tipi di account supportati: Account in qualsiasi directory
  5. URI di reindirizzamento:
  6. Clicca su Registra e copia il ID applicazione (client)
  7. Vai su Permessi API → Aggiungi un permesso → Microsoft Graph → Permessi delegati
  8. Cerca e seleziona Calendars.Read e Calendars.Read.Shared
  9. Clicca su Concedi il consenso amministratore

🔴 Per Google Calendar:

  1. Vai su Google Cloud Console
  2. Crea un nuovo progetto o selezionane uno esistente
  3. Vai su API e servizi → Libreria → cerca Google Calendar API e abilitala
  4. Vai su Credenziali → Crea credenziali → ID client OAuth
  5. Tipo applicazione: Applicazione web
  6. Nome: Agenda Unita
  7. URI di reindirizzamento autorizzati:
  8. Copia il Client ID e l'API Key (se necessaria)
Nota: Assicurati che gli URI di reindirizzamento corrispondano esattamente all'URL di questa pagina.
